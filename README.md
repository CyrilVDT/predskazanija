# Соляр — солнечный гороскоп онлайн

Сайт строит солнечную карту (соляр) по дате, времени и месту рождения и коротко объясняет, что ждёт в году. Внутри: календарь по дням, прогнозы по месяцам, карта соляра, обзор по годам и жизненные циклы.

Положения планет считаются прямо в браузере. Сайт работает без сервера и сборки. Точность сверена с эфемеридами NASA JPL Horizons.

Астрология — это интерпретация, а не наука.
